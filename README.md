# SutraCrochet E-Commerce Platform

A bespoke, headless e-commerce website for handcrafted crochet items and fine jewelry. 

## Project Overview
This project serves as the digital storefront for SutraCrochet. It is built with a focus on a clean, dark-themed UI, responsive design, and seamless cart functionality without the overhead of a heavy CMS.

## Tech Stack
* **Frontend:** HTML5, CSS3 (Vanilla)
* **E-Commerce:** Snipcart (Headless Cart API)
* **Deployment:** Netlify 

## Key Features
* Collapsible, responsive side navigation.
* "Shopify-style" floating cart and customer account portals.
* Secure checkout using Snipcart integrated with Indian Rupees (INR).
* Pure CSS hover states and interactive 3D product cards.
